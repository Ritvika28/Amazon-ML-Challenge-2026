# Data Directory Structure & Guidelines

## Directory Overview

- `raw/`: Unmodified official competition files.
- `processed/`: Intermediate datasets, normalized versions, and blocking output files generated by the pipeline.

## Guidelines

- Raw competition files must be placed directly inside `data/raw/`.
- Processed datasets will be generated programmatically into `data/processed/`.
- **Raw data must NEVER be modified manually or overwritten.**
- Dataset filenames and column schemas must be discovered directly from the actual competition files during Exploratory Data Analysis (EDA).
- **No external data** (geocoding, external business registries, web scraping, etc.) should be added or used.
